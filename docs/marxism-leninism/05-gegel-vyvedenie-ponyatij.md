# Гегель: выведение понятий — структура данных для «древа»

> Подготовка структуры данных под будущий экран-«древо», где видно, **что из чего вытекает** в «Науке логики» Гегеля.
> Данные лежат в [`gegel-dialektika.json`](gegel-dialektika.json).

**Три источника расшифровки** на каждое понятие:
1. `popov` — М. В. Попов, «„Наука логики“ Гегеля. Пособие по изучению» (материалистическая трактовка).
2. `hegel` — собственно «Наука логики» Гегеля (идеалистический оригинал).
3. `svremya` — шпаргалки «Путеводитель по диалектике» (svremya.org, на основе Попова и Мазур).

## 1. Принцип выведения (схема)

У Гегеля все понятия выводятся **одно из другого**: каждое понятие, раскрывая своё внутреннее противоречие, переходит в следующее. Начало — **чистое бытие**, конец — **абсолютная идея**.

Порядок выведения в данных дан в **материалистической переработке** (Попов/Мазур). Три учения (секции) и их под-отделы (`subsection`):

- **Учение о бытии** (объективная логика): Определённость (Качество) → Величина (Количество) → Мера.
- **Учение о сущности**: Рефлексия → Явление → Действительность.
- **Учение о понятии** (субъективная логика): Объективность → Субъективность → Идея.

> **Главное отличие от Гегеля (материалистическое «переворачивание»).** У Гегеля «Учение о понятии» открывается Субъективностью (Понятие→Суждение→Умозаключение), затем Объективность (Механизм→Химизм→Телеология), затем Идея (Жизнь→Познание→Абсолютная идея). В переработке Попова/Мазур порядок переставлен: сначала **Объективность** (Механизм→Химизм→**Жизнь**), затем **Субъективность** (Понятие→Суждение→Умозаключение), затем **Идея** (Идея истины→Идея добра→Абсолютная идея). Жизнь перенесена из Идеи в Объективность, Телеология — в Идею добра.

Скелет цепочки (полная лестница из 65 узлов — см. JSON):

```
Чистое бытие → Ничто → Становление → Наличное бытие → Качество → Нечто →
Иное → Изменение → Граница → Конечное → Бесконечное → Для-себя-бытие → Одно →
Отталкивание/Притяжение → Количество → Определённое количество → Число →
Степень → Количественное отношение → Мера → Масштаб → Узловая линия мер →
Безмерное ─▶ Сущность → Видимость → Рефлексия → Тождество → Различие →
Разность → Противоположность → Противоречие → Основание → Форма/Материя →
Содержание → Условие → Существование → Вещь → Свойство → Явление → Закон →
Существенное отношение → Целое/Части → Сила/Проявление → Внутреннее/Внешнее →
Абсолютное → Действительность → Возможность → Случайность → Необходимость →
Субстанция → Причина → Действие → Взаимодействие ─▶ Механизм → Химизм →
Жизнь → Обмен веществ → Род ─▶ Понятие → Суждение → Умозаключение ─▶
Идея → Идея истины → Идея добра → Абсолютная идея
```

## 2. Структура данных (схема JSON)

```jsonc
{
  "schemaVersion": "1.1",
  "title": "…",
  "sources": { "popov": "…", "hegel": "…", "svremya": "…" },
  "root": "chistoe-bytie",
  "orderNote": "…",                    // пояснение материалистической перестановки
  "sections": { "bytie": "…", "suschnost": "…", "ponyatie": "…" },
  "nodes": [
    {
      "id": "chistoe-bytie",          // slug (ключ для связей)
      "order": 1,                     // порядковый номер в лестнице выведения
      "term": "Чистое бытие",         // русское название
      "german": "das reine Sein",     // оригинальный термин (пусто, если нет)
      "parent": null,                 // id понятия, из которого выведено (null у корня)
      "section": "bytie",             // учение: bytie | suschnost | ponyatie
      "subsection": "Определённость (Качество)", // под-отдел внутри учения
      "popov": "…",                   // расшифровка №1 (Попов)
      "hegel": "…",                   // расшифровка №2 (Гегель)
      "svremya": "…",                 // расшифровка №3 (шпаргалки svremya.org)
      "derivation": "…"               // как выводится из parent (кратко)
    }
  ]
}
```

### Поля
| Поле | Тип | Назначение |
|---|---|---|
| `id` | string | уникальный ключ, используется в `parent` для построения связей |
| `order` | int | порядковый номер понятия в лестнице выведения |
| `term` | string | русское название понятия |
| `german` | string | немецкий оригинал (Гегель); пустая строка, если термин неоднозначен |
| `parent` | string \| null | понятие-предшественник (ребро «из чего вытекает») |
| `section` | string | учение: `bytie` \| `suschnost` \| `ponyatie` |
| `subsection` | string | под-отдел внутри учения (группировка триад) |
| `popov` | string | **расшифровка №1** — материалистическая трактовка (книга Попова) |
| `hegel` | string | **расшифровка №2** — собственно из «Науки логики» Гегеля |
| `svremya` | string | **расшифровка №3** — шпаргалка «Путеводитель по диалектике» (svremya.org) |
| `derivation` | string | пояснение перехода от `parent` к данному понятию |

## 3. Как это ляжет на «древо»

- Ребро дерева = поле `parent` (каждое понятие указывает, из чего выведено).
- Порядок лестницы = поле `order` (65 шагов).
- Группировка по `section` = три ствола (бытие / сущность / понятие); по `subsection` = девять под-отделов (по три на учение).
- Для каждого узла показываются три расшифровки: `popov`, `hegel`, `svremya`.
- Флаг `orderNote` на верхнем уровне подсказывает экрану, где лежит материалистическая перестановка (Учение о понятии).
