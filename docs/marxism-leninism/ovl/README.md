# Цикл «Основное в ленинизме» (ОВЛ) — конспекты

Конспекты к книгам серии **«Основное в ленинизме»** (изд. группы «Свободное
время» / журнал «Корпоративные университеты», ред. Марат Удовиченко и др.).
Серия перепечатывает фундаментальные работы Ленина **по Полному собранию
сочинений (ПСС), изд. 5-е** — каждый том синхронизирован с соответствующим
томом ПСС, работы даны в хронологическом порядке, как их писал Ленин.

В приложении доступны **17 книг**: 16 томов Ленина (1893–1908) + том Сталина
(1901–1913). PDF скачиваются напрямую с `https://svremya.org/appws/pdf/`.

## Зачем это здесь

Цель — «погрузиться в теорию» и получить базу, к которой удобно возвращаться
и которую легко расширять. Каждый конспект строится по одной схеме:

1. **Состав тома** — какие работы вошли и в каком году написаны.
2. **Контекст эпохи** — против кого и за что боролся Ленин в этот период.
3. **Основные тезисы** — ядро аргументов по каждой работе.
4. **Вопросы для самопроверки** — база для будущего квиза.
5. **Ключевые цитаты** — точные выдержки из текста.
6. **Расширение** — куда копать дальше (ПСС, видеоразборы).

## Сквозная логика 16 томов Ленина (1893–1908)

16 томов охватывают **формирование ленинизма** как теории и практики:

1. **1893–1900 — размежевание с народничеством и «легальным марксизмом»**
   (тт. I–IV). Ленин доказывает, что Россия идёт по капиталистическому пути,
   а значит, революционным классом становится пролетариат, а не «община».
2. **1900–1903 — строительство партии** (тт. V–VII). «Искра», борьба с
   «экономизмом» («Что делать?»), выработка программы РСДРП.
3. **1903–1905 — борьба с меньшевизмом** (тт. VIII–X). «Шаг вперёд, два шага
   назад»: партия как авангард и организация профессиональных революционеров.
4. **1905–1908 — первая русская революция и её уроки** (тт. XI–XVI).
   «Две тактики», опыт Советов, партизанской борьбы, думская тактика, аграрная
   программа.

Том Сталина (1901–1913) примыкает к этой логике: «Марксизм и национальный
вопрос» (1913) — классика по национальному вопросу, написанная в тот же
период.

## Как расширять

Конспекты — «скелет». Дополнить можно тремя путями:
- **вглубь** — добавлять тезисы и цитаты по конкретной работе (текст томов в ПСС);
- **вширь** — по каждому «Вопросу для самопроверки» собрать квиз в JSON
  (пример формата см. в `../quiz-citati.json`);
- **связи** — линковать работы между томами (например, «Что делать?» → «Шаг
  вперёд, два шага назад» → «Две тактики»).
