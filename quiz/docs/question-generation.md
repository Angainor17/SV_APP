# Генерация вопросов для квизов из книг

**Дата создания:** 2026-07-25

---

## 1. Общий workflow

```
Книга (EPUB/PDF/DOC)
    ↓
Извлечение текста по главам
    ↓
LLM (Claude/GPT) с промптом
    ↓
JSON с вопросами
    ↓
Загрузка в Wiki (Quiz:Название_квиза)
    ↓
Готово к использованию в приложении
```

---

## 2. Подготовка книги

### 2.1 Рекомендуемый формат: EPUB

**Почему EPUB:**
- Структурирован по главам
- Легко извлечь текст
- Сохраняется форматирование

**Инструменты для извлечения:**
- Calibre (GUI)
- pandoc (CLI): `pandoc book.epub -t plain -o book.txt`
- Python: библиотека `ebooklib`

### 2.2 Извлечение из PDF

**Инструменты:**
- `pdftotext` (CLI)
- Adobe Acrobat Pro
- Онлайн-конвертеры

**Совет:** После конвертации проверьте структуру - главы должны быть разделены.

## 3. Мастер-промпт для генерации вопросов

### 3.1 Базовый промпт (для главы)

```markdown
# Задача: Создание вопросов для квиза по книге

Ты — эксперт по созданию образовательных тестов. Создай вопросы для квиза на основе текста главы книги.

## Контекст книги
Название: [НАЗВАНИЕ КНИГИ]
Автор: [АВТОР]
Глава: [НОМЕР И НАЗВАНИЕ ГЛАВЫ]

## Текст главы
"""
[ВСТАВИТЬ ТЕКСТ ГЛАВЫ - до 10-15 тысяч символов]
"""

## Требования к вопросам

### Количество
Создай 8-12 вопросов в зависимости от объёма информации в главе.

### Типы вопросов
1. **Фактические** (40%) - даты, имена, термины
2. **Понимание** (40%) - причины, следствия, взаимосвязи
3. **Анализ** (20%) - главные идеи, выводы

### Правила
- Каждый вопрос проверяет ОДНУ идею
- 4 варианта ответа (A, B, C, D)
- Ровно один правильный ответ
- Все варианты правдоподобны (без очевидно ложных)
- Правильный ответ распределён случайно (не всегда первый)
- Для каждого вопроса — пояснение (1-3 предложения)

### Чего избегать
- Вопросы типа "какого цвета..." (несущественные детали)
- Двойные вопросы в одном
- Слишком лёгкие вопросы ("Да/Нет")
- Слишком сложные формулировки

## Формат вывода (JSON)

```json
{
  "quiz_title": "Название книги: Глава X",
  "theme": "Тема квиза",
  "questions": [
    {
      "id": "q1",
      "question": "Текст вопроса?",
      "type": "single",
      "answers": [
        {"id": "a1", "text": "Вариант A", "correct": false},
        {"id": "a2", "text": "Вариант B", "correct": true},
        {"id": "a3", "text": "Вариант C", "correct": false},
        {"id": "a4", "text": "Вариант D", "correct": false}
      ],
      "explanation": "Краткое пояснение правильного ответа."
    }
  ]
}
```

Выведи результат в формате JSON выше.
```

### 3.2 Промпт для всей книги (по частям)

```markdown
# Задача: Извлечение ключевых идей книги

Ты — аналитик текста. Извлеки ключевые идеи, факты и тезисы из текста книги для создания квиза.

## Текст (часть [N] из [M])
"""
[ТЕКСТ ФРАГМЕНТА]
"""

## Задача
Извлеки:
1. 5-10 ключевых идей/тезисов
2. 10-20 важных фактов (даты, имена, термины)
3. 3-5 важных цитат (для вопросов на понимание)

## Формат вывода

### Ключевые идеи:
1. [Идея 1]
2. [Идея 2]
...

### Факты:
- [Факт 1]
- [Факт 2]
...

### Цитаты:
> "[Цитата]" (контекст)

После извлечения всех частей, запусти генерацию вопросов по собранным данным.
```

## 4. Пример использования

### Шаг 1: Подготовка главы

```bash

```

### Шаг 2: Генерация вопросов

Загрузить в Claude/GPT промпт с текстом главы.

### Шаг 3: Проверка

- Убедиться, что вопросы релевантны книге
- Проверить правильность ответов
- Отредактировать при необходимости

### Шаг 4: Загрузка в Wiki

Создать страницу `Quiz:Название_книги` с полученными вопросами.

## 5. Скрипт для автоматизации

### 5.1 Python-скрипт для извлечения глав

```python
#!/usr/bin/env python3
"""
extract_chapters.py - Извлечение глав из книги для генерации квизов
"""

import ebooklib
from ebooklib import epub
import argparse
import json
import os

def extract_chapters(epub_path, output_dir):
    """Извлекает главы из EPUB в отдельные файлы"""
    book = epub.read_epub(epub_path)

    os.makedirs(output_dir, exist_ok=True)

    chapters = []
    for item in book.get_items():
        if item.get_type() == ebooklib.ITEM_DOCUMENT:
            content = item.get_content().decode('utf-8')
            # Простой extraction текста из HTML
            # В реальности нужен BeautifulSoup
            chapters.append(content)

    for i, chapter in enumerate(chapters):
        with open(f"{output_dir}/chapter_{i+1}.txt", 'w') as f:
            f.write(chapter)

    print(f"Извлечено {len(chapters)} глав в {output_dir}")

def generate_prompt(chapter_text, book_title, chapter_num):
    """Генерирует промпт для главы"""
    prompt = f"""# Задача: Создание вопросов для квиза

Книга: {book_title}
Глава: {chapter_num}

Текст главы:
"""
{chapter_text[:15000]}  # Ограничение по длине
"""

Создай 8-10 вопросов в JSON формате:
```json
{{
  "quiz_title": "{book_title}: Глава {chapter_num}",
  "questions": [
    {{
      "question": "...",
      "answers": [
        "{{"text": "...", "correct": false}}",
        "{{"text": "...", "correct": true}}",
        "{{"text": "...", "correct": false}}",
        "{{"text": "...", "correct": false}}"
      ],
      "explanation": "..."
    }}
  ]
}}
```
"""
    return prompt

if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    parser.add_argument('epub_file', help='Путь к EPUB файлу')
    parser.add_argument('--output', '-o', default='chapters', help='Папка для вывода')
    parser.add_argument('--title', '-t', default='Книга', help='Название книги')

    args = parser.parse_args()
    extract_chapters(args.epub_file, args.output)
```

## 6. Рекомендации по типам книг

| Тип книги | Фокус вопросов | Пример вопроса |
|-----------|----------------|----------------|
| **Художественная** | Персонажи, сюжет, темы | "Какое решение принял герой в главе 5?" |
| **Научно-популярная** | Ключевые идеи, факты | "Какую закономерность описывает автор?" |
| **Биография** | Даты, события, решения | "В каком возрасте X сделал Y?" |
| **Техническая** | Методы, алгоритмы | "Какой подход рекомендуется для Z?" |
| **Философская** | Концепции, аргументы | "Какую позицию занимает автор относительно Z?" |

---

## 7. Чек-лист качества вопросов

- [ ] Вопрос понятен без контекста
- [ ] Только один правильный ответ
- [ ] Все варианты правдоподобны
- [ ] Нет очевидных подсказок
- [ ] Пояснение добавляет ценность
- [ ] Вопрос проверяет понимание, не память
- [ ] Формулировка не слишком длинная
